# A Personal Library of Useful Knowledge

This journal collects practical AI tips, useful links, and lessons worth keeping.

The goal is simple: **save useful information, organize it, and find it again when needed.**

## How to use this journal

- **Browse categories** to explore different subjects.
- **Browse tags** to find related notes.
- **Follow the links** to revisit original resources.
- **Keep notes brief** so the most useful information is easy to remember.

## Built for long-term learning

The notes are stored in Markdown, making them easy to edit, back up, and eventually compile into an EPUB ebook.
